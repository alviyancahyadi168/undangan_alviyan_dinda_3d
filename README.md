# Undangan Alviyan & Dinda — 3D Prototype

Prototype tahap 1: opening 3D + memories gallery.

## Cara mencoba
Buka `index.html` di browser.

## Deploy ke GitHub Pages
1. Upload seluruh isi folder ini ke repository `undangan_alviyan_dinda_3d`.
2. Pastikan `index.html` berada di root repository.
3. GitHub → Settings → Pages → Deploy from branch → pilih branch utama dan folder `/ (root)`.
4. Tunggu proses deploy selesai.

## Catatan
Prototype ini sengaja dipisahkan dari undangan production lama. RSVP Google Sheets belum disentuh pada tahap prototype ini.
